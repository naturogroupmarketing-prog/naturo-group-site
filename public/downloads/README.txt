Drop the lead-magnet PDFs in this directory.

Files referenced by the codebase:
  • naturo-bond-back-checklist.pdf — used as the default download for
    <LeadMagnet /> when no `downloadUrl` prop is passed (see
    src/components/LeadMagnet.astro).

Filenames are cited in the LeadMagnet component as defaults; if you
rename the asset, update the component prop default to match. Until the
real PDF is dropped here the LeadMagnet form will still capture the
lead, but the download anchor will 404.

Recommended:
  - naturo-bond-back-checklist.pdf      (~12 pages, A4, branded cover)
  - naturo-eco-friendly-cleaning-guide.pdf
  - naturo-ndis-cleaning-info.pdf
